# Security Policy

## Supported Versions

Glint actively maintains the latest minor version line. Security patches are prioritized and released promptly.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

We take the security and privacy of Glint users seriously. If you discover a security vulnerability, **please do not open a public GitHub issue**.

### How to Report

1. **Email Us Privately**: Send details of the vulnerability to [security@glint.dev](mailto:security@glint.dev) or [dev@glint.dev](mailto:dev@glint.dev).
2. **Private Advisory**: Alternatively, you can use the [GitHub Security Advisory feature](https://github.com/joychandrauday/glint/security/advisories/new) to report the vulnerability privately.

### What to Include

Please provide:
- A description of the issue and its potential impact.
- Exact steps or proof-of-concept scripts to reproduce the behavior.
- Operating system, architecture, and Glint version tested.
- Any proposed fix or remediation suggestions.

### Our Commitment

- **Acknowledgment**: We will acknowledge receipt of your report within **48 hours**.
- **Investigation & Patch**: We will investigate and provide a timeline or fix within **14 days**.
- **Responsible Disclosure**: We request that you give us adequate time to publish a fix before sharing details publicly. We will gladly credit you in release notes upon publication.
